**踩了两个坑（已写进技能 §4.2.1 与 §九）**：
1. **页脚插入没做幂等保护** → 脚本第二遍运行时 515 个文件出现两条署名链接。
2. **修重复时把正则源串当成了替换文本** → `href="[^"]*"` 这个字面量被写进 515 个文件。
最终改为「先全删、再重建」：删除时用**链接文字**锚定（href 已不可信），重建时按深度算路径。
终检 517/517 达标（1034 条回主站入口 + 517 条署名），链接数 22404 → 23955，正好 +1551 条新增。
3. 边界：`depth 0` 的页面 `data-root` 是 `"./"` 而非空串，导致 `index.html` 与 `404.html`
   第一遍被整体跳过，需要补跑。
