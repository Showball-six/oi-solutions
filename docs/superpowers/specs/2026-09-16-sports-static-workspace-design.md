# Sports 静态健身工作台：设计规格

**日期：** 2026-09-16
**状态：** 已确认，待实现计划
**范围：** 在项目根目录新建独立的 `sports/` 静态小项目；不修改 OI 主站入口、导航或数据。

## 目标

构建一个可由静态 JSON 维护的个人健身信息页，用于查阅：

1. 以早餐、午餐、晚餐组织的食物构成及食材生重；
2. 根据性别、当前体重和每周运动时长换算减脂期的每日宏量营养素目标及基础餐单生重；
3. 按推、拉、腿三分化浏览训练动作、组次逻辑、注意事项和简化动画示意。

本项目不保存用户输入，不接入账号、后端或云端同步。换算仅在浏览器内完成，刷新后重置为 JSON 默认值。

## 依据与边界

饮食规则来自项目内的 `sports/references/2026-09-16-减脂换算规则.md`：视频只提供减脂期、按性别和每周运动时长分组的蛋白质/碳水/脂肪系数。增肌和维持只能作为食谱筛选标签，不展示未经来源支持的自动换算值。

训练计划来自 `sports/references/2026-09-16-三分化训练摘要.md`：推日（胸/中束/三头）、拉日（背/后束/二头）、腿日（偏后侧链与髋稳定）各五个动作。页面保留原视频链接，并明确动作说明不能替代针对伤病、疼痛或特殊人群的线下专业指导。

不下载、截取或转载 Bilibili 视频画面。每个动作使用原创、抽象的 SVG 运动方向示意；它表达轨迹与发力方向，而非替代完整的教学视频。

## 信息架构与交互

单页面按顺序包含：

1. **概览区**：项目定位、静态数据来源、低风险提示。
2. **减脂换算器**：性别单选、体重数值输入、每周运动时长选择。输入更新后，实时显示三项每日宏量目标；当选择“增肌”或“维持”时明确显示“暂未提供换算规则”。
3. **三餐食谱区**：目标标签筛选；每张餐次卡显示食材、生重、缩放后重量和备注。减脂基础餐单按 `当前体重 / 85` 进行食材生重缩放，并标明该比例仅适用于来源中的 85 kg、男性、每周 2–3 小时运动示例。
4. **三分化训练区**：推/拉/腿切换标签，每个训练日显示训练目标和恢复提示。动作卡支持展开；展开后显示原创 SVG 动画、起始组次、余量/力竭说明、注意事项、替代/退阶信息以及原视频链接。

键盘可操作所有输入、标签和折叠按钮；动画会响应 `prefers-reduced-motion` 并切换为静态示意。

## 文件与数据模型

```text
sports/
  index.html              页面语义结构
  styles.css              独立视觉样式与动画
  app.js                  JSON 加载、换算、筛选和卡片渲染
  data/
    nutrition.json        减脂规则、三餐模板、目标标签
    training.json         三日训练、动作提示、动画参数和来源链接
  references/
    2026-09-16-减脂换算规则.md
    2026-09-16-三分化训练摘要.md
  README.md               本地预览与 JSON 维护说明
```

`nutrition.json` 中的规则以 `sex × weeklyHoursBand → {carbs, protein, fat}` 建模，单位统一为 `g/kg`。食材条目保留 `baseRawGrams` 或 `baseCount`、`scaleWithWeight` 与 `note` 字段。

`training.json` 中的动作包含 `name`、`focus`、`prescription`、`effort`、`cues`、`warnings`、`substitution`、`animation` 与 `sourceUrl`。`animation` 为图形参数（起止位置、运动方向、节奏），不保存或嵌入第三方视频媒体。

## 视觉方向

页面为独立的深色训练日志风格：暖灰背景、石墨黑卡片、乳白文字和少量青柠绿作为状态/进度强调色。版式使用醒目的数字数据、克重等宽显示和紧凑但易扫描的卡片层级。食谱以明亮的暖色点缀，推/拉/腿分别以三种低饱和强调色区分，避免与 OI 主站复用品牌视觉。

## 异常与验证

- JSON 请求失败时，页面显示明确的本地数据加载提示及静态错误状态，不显示误导性的计算结果。
- 体重必须为 30–250 kg；无效输入会恢复到默认值并给出输入提示。
- 无可用公式的目标不运行计算器；只保留数据浏览功能。
- 检查所有 JSON 可解析、页面引用完整、宏量公式在四个运动时长区间及两种性别下正确计算、三餐缩放与 85 kg 基准一致。
- 通过浏览器在桌面与窄屏宽度验证布局、折叠、键盘导航和减少动画偏好。

## 非目标

- 不提供医学诊断、热量处方、体脂预测或补剂建议。
- 不提供登录、打卡、历史数据、后端写入或多设备同步。
- 不在未获得来源规则前为增肌/维持生成自动克重公式。
