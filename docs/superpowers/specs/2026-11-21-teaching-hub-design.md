# Showball OI 教学入口与笔试题库改版方案（待确认）

## 目标与已确认范围

面向信息学教师备课、课堂训练与学生课后复习。用户选择「完整教学入口」：迁入远明刷题中心的笔试练习，并统一首页、课程、题解和工具导航，保留已有讲义、题解地址及学生进度。

成功标准：学生从首页可直接进入课程或指定考试练习；教师仍能用现有 JSON 与 CLI 维护内容；静态部署到原 GitHub Pages 域名，不新增服务器或账号系统。

## 视觉方向（实施建议，待用户确认）

以参考站的任务分类和紧凑入口为方向，采用清晰中文排版、白底、细分隔线与适度留白，不照搬其品牌图标或未确认的视觉细节。

- 主色延续当前天蓝：强调 `#0284c7`；浅色文字 `#17212f`、次要文字 `#536273`、背景 `#ffffff`、分隔线 `#e5e9ef`、轻背景 `#f6f8fa`。
- 暗色保留：背景 `#10151d`、正文 `#e5edf5`、分隔线 `#2a3543`、强调 `#7dd3fc`。
- 中文正文优先 Noto Sans SC 与系统中文字体，代码用现有等宽字体。正文 16px，控件与导航至少 14px，次要元信息 13px；搜索与标题有明确层级。
- 阅读区最大宽度约 1120px；讲义阅读保持自身版式；练习页用正文与答题卡双栏，窄屏答题卡折叠。
- 降低大圆角、阴影、渐变与悬浮位移的使用。分类入口以小图标、名称和一句说明组成，信息优先。
- 颜色不得覆盖洛谷难度及 AC/尝试/未提交的语义；键盘焦点明确，支持 reduced-motion。

实施时创建 `DESIGN.md` 记录最终设计，并更新已落后的 AGENTS.md 中本次涉及的架构说明，避免后续维护继续按旧版修改。

## 笔试题库的数据与迁移

建议目录：

```text
exams.html                     试卷目录
exams/practice.html            统一答题页，?paper=<稳定 id>
exams/catalog.json             轻量目录索引，不含完整题目
exams/papers/<id>.json         经校验的题目数据
exams/assets/                  必要图片、公式与代码渲染依赖
exams/SOURCES.md               署名、许可声明位置、版本与来源
scripts/import_exams.py        可重复导入、校验及生成目录
```

上游数据按固定 commit 导入，记录 commit、路径、来源 URL、导入时间与文件摘要。稳定 id 从源目录产生，防止后续同步造成成绩错配。解析数据后统计分类、题型与资源，逐项检查 ID 唯一性、答案格式、总分及资源引用；异常试卷不静默修正，输出明确报告。保留原分类与级别，首页重点展示 GESP、CSP-J、CSP-S，NCT 和其他赛事仍可进入。

迁移为本地数据与必要资源，不使用 iframe 嵌站；作答不依赖上游站点在线。保留或替换确有必要的 Markdown/公式/代码渲染库时须检查许可并本地存储；禁止执行题目内的 HTML 脚本。不得复制上游统计、广告、跟踪、作者联系方式或站点配置。

全站搜索加入试卷标题、分类、级别与年份，只加载目录索引；不在首页下载完整题库。试卷页按需读取一份数据。

## 练习体验与行为约定

目录支持分类、级别、年份、关键词和分页；筛选状态写入 URL，返回时可恢复；筛选变更回到第一页。包含加载、加载失败重试、无结果与清空筛选入口。

练习页显示标题、来源、题量、时长和评分规则。支持单选、多选、判断、填空与编程题展示；先核对实际题型，再决定缺失字段的处理。客观题可按答案评分；没有客观判分依据的填空题列明限制；编程题提供题目与代码草稿，未接入评测时明确标注「编程题不自动评分」，不能假装运行代码或给出 AC。

提供答题卡、已答数量、练习模式与限时模式。练习模式默认无强制交卷；限时模式明确开始，使用截止时间计算剩余时长，刷新不会重置，超时后交卷。交卷前显示未答数量，允许返回检查。交卷后展示客观题得分、满分口径、正确答案、错题筛选与题目原有解析，不生成不存在的解析。

答案、代码草稿、最高客观题成绩和错题记录保存在当前浏览器；数据带格式版本、稳定试卷 ID 与试卷版本。存储不可用时显示「本次记录无法保存」，答题仍可继续。清空或重做采用页面内确认，不使用浏览器 alert/confirm。默认不收集学生姓名和身份，不向外部上传练习记录。

学生提交矩阵继续由 `students/submissions.json` 提供，与本地笔试记录分开。此次不承诺跨设备同步、教师远程查看笔试成绩、账号系统或编程在线评测；这些需要另行设计数据与权限。
