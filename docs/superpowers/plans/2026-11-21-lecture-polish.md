# Modern Textbook Lecture Polish

**Goal:** 优化用户现有 `python script.py polish` 加工流程，采用已确认的现代教材风格。
**Architecture:** 保持 Typora 正文与原始样式不变，由 script.py 唯一生成共享 CSS/JS；不增加前端框架。
**Design:** 墨蓝标题、白色阅读页、明确章节层级、中性表格与代码区、克制的提示语义色。讲义独立阅读界面保留主站返回入口与主题选择，桌面章节目录、手机折叠目录。打印展开代码并隐藏操作界面。

## Tasks
- [x] 加工器回归：注入幂等、原始正文保护、大小写/属性兼容、完整讲义集合、只读预览。
- [x] 重写 LECTURE_THEME_CSS：排版、提示区、例题、公式、表格、代码、响应式、深浅主题和打印。
- [x] 增强阅读脚本：章节目录、标题锚点、阅读位置提示、主题切换、代码操作可访问性与错误反馈；保留标记解析和 iframe 演示。
- [x] 运行 polish 应用现有讲义；真实 Typora CodeMirror、MathJax、KaTeX、演示 iframe 与手机截图验证。
- [x] 独立代码审阅，修复实质问题，更新维护说明并提供本地预览。

## Decisions
- 用户明确选择现代教材方向，本轮直接优化现有命令，不另建与主站割裂的专栏。
- 标题与正文不改写、不猜测提示类型；不为没有语义前缀的普通引用强加定义标签。
- 代码的 @open/@fold 标记及默认展开阈值继续兼容。
- 仅修改脚本生成的增强层，不重写 Typora 原生 CSS，不推送远端。


## 验证记录
- 45 份讲义应用新增强层；二次加工文件摘要不变。
- 14 项 Python 测试通过，生成 JS 语法检查通过。
- Edge 浏览器验证：真实 Typora/CodeMirror、公式保留、目录锚点、代码展开标记/复制、主题、打印、390px 手机布局、剪贴板失败反馈、重复执行不叠加。
- 独立审阅的一项 P2（内嵌脚本字符串中的结束标签被误识别）通过 HTMLParser 源位置注入修复，回归测试已覆盖脚本字符串、注释与 iframe srcdoc。
- 现代教材样式由单一脚本常量生成，Typora 原生内联样式未重写。无远程提交或发布。


## 趣味视觉迭代
用户反馈现代教材过于普通，调整为算法实验笔记：蓝色点阵背景、白色圆角纸面、标题荧光标记与代码符号签、章节页签、彩色批注便签及实验卡片式代码框。正文、目录结构与已有交互保持；打印隐藏装饰。该变化优先于前文原始视觉描述，DESIGN.md 已同步更新。


## 目录格式与无抬头栏
用户要求目录支持 Markdown 并移除顶部栏。目录改为继承标题已渲染的行内结构，保留代码、强调与 MathJax/KaTeX 公式，移除嵌套链接和事件处理器，重命名克隆公式 ID 与引用。增加动态更新；主题/打印控件移入目录底部。浏览器回归包含真实素数筛讲义的公式目录、ID 隔离及目录动态更新。
